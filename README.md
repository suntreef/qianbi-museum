# 钱币博物馆藏品入库系统

拍照 → 自动识别评级信息 → 人工确认 → 一物一档。
面向民间博物馆的本地化藏品管理系统，全部数据留在自己的 NAS 上。

## 部署（NAS · Docker）

**方式一：拷贝文件夹（最简单，不需要 NAS 上装 git）**

1. 把整个 `qianbi-museum` 文件夹拷到 NAS（File Station 拖拽 / SMB 共享）
2. 编辑 `docker-compose.yml`：`APP_PASSWORD` 必改；`LLM_API_KEY` 可选
3. 打开 **Container Manager → 项目 → 新增**，指向该文件夹，构建启动
   （或 SSH 进入该目录执行 `docker compose up -d --build`）

**方式二：git 拉取（便于以后更新）**

```bash
git clone https://github.com/suntreef/qianbi-museum.git
cd qianbi-museum
# 编辑 docker-compose.yml 改密码
docker compose up -d --build
```

以后更新：`git pull && docker compose up -d --build`

启动后手机/电脑浏览器访问 `http://NAS的IP:8300`，先看 `/api/health` 确认服务正常。

## 备份（重要）

`data/` 目录 = SQLite 数据库 + 全部照片，**整个系统的全部家当**。三种方式：

1. **一键下载**（管理员登录 → 藏品页 →「💾 备份数据库」）：下载一致的数据库快照文件
2. **NAS 计划任务**（推荐，全自动）：项目自带 `scripts/backup.sh`，
   群晖「控制面板 → 任务计划 → 新增 → 用户定义的脚本」每天凌晨执行，
   数据库一致性打包 + 照片增量同步到第二块盘/异地目录（脚本内改两行路径即可）
3. **手动**：停机或低峰期直接复制 `data/` 目录

提醒：RAID 不是备份，务必有第二份。

## 环境要求

- NAS 可访问外网（抓评级公司证书页 + 调大模型 API）
- 手机与 NAS 同一局域网；远程录入可加 Tailscale 等组网工具
- （可选）大模型 API Key：智谱免费档（GLM-4V-Flash 系列，0 元）或硅基流动免费模型，
  任意 OpenAI 兼容接口均可；不填也完全能用

## 用户与权限

首次启动自动创建管理员账号 `admin`（口令 = docker-compose.yml 里的 `APP_PASSWORD`，**务必修改**）。
管理员登录后在「用户」页为员工开账号：

| 角色 | 权限 |
|---|---|
| 管理员 | 全部：价格/估值、Excel 导出、删除档案、字典与用户管理 |
| 录入 | 拍照录入、修改藏品信息、删除照片；**看不到价格和估值** |
| 只读 | 仅浏览检索；看不到价格和估值 |

- 口令 pbkdf2 加密存储，数据库不存明文
- 连续输错 5 次锁定来源 IP 10 分钟（防暴力破解）
- 改价请求对非管理员在服务端直接丢弃，改前端也没用

## 数据量与安全（为几千 → 几万件设计）

- 品类/系列/机构/券种/印刷厂/文书/朝代/评级公司/年份/状态 **全部有索引**，筛选不随数据量变慢
- 自由文本搜索走 **SQLite FTS5 中文全文索引**（trigram 分词，3 字以上子串检索），
  十万级毫秒响应；不足 3 字自动降级 LIKE，老环境不支持 FTS 也自动降级
- 全部 SQL 参数化（防注入）；列表页输出 HTML 转义（防 XSS）
- 二维码只允许公网 http(s) 地址（防 SSRF 内网探测）；上传图片限 16MB 且服务端重新编码
- 单机 SQLite 到约 50 万条都很从容；之后可迁 PostgreSQL（字段设计已兼容）

## 项目结构

```
qianbi-museum/
├── docker-compose.yml      # NAS 部署编排
├── Dockerfile
├── requirements.txt
├── app/
│   ├── main.py             # FastAPI 入口
│   ├── config.py           # 环境变量配置
│   ├── models.py           # SQLite 建表
│   ├── seeds/              # 字典初始数据（机构/券种/印刷厂/朝代…）
│   ├── ingest.py           # 识别流水线（待开发）
│   ├── adapters/           # 证书抓取适配器（待开发）
│   ├── services/           # 二维码/大模型/查重/导出（待开发）
│   └── web/                # 采集页 + 管理后台（待开发）
└── data/                   # 运行时生成：数据库 + 照片（备份这个目录）
```
